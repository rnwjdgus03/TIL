# 장점

- **최신 정보 반영**: 모델을 다시 학습시키지 않아도 새로운 문서를 추가하면 최신 정보를 활용할 수 있습니다.
- **환각(Hallucination)*감소**: 근거 문서를 바탕으로 답변하므로 잘못된 정보를 지어낼 가능성이 줄어듭니다.
- **사내 데이터 활용**: 기업의 내부 문서나 매뉴얼 등 학습되지 않은 정보도 사용할 수 있습니다.
- **모델 재학습 불필요**: 문서만 업데이트하면 되므로 유지 비용이 낮습니다.

---

# 단점

- **검색 성능에 크게 의존**: 관련 문서를 제대로 찾지 못하면 답변 품질도 떨어집니다.
- **속도가 다소 느릴 수 있음**: 검색 과정을 거친 뒤 답변을 생성하기 때문입니다.
- **문서 품질의 영향**: 오래되었거나 잘못된 문서를 검색하면 그 내용을 바탕으로 잘못된 답변을 생성할 수 있습니다.

Knowledge cutoff은 LLM이 학습한 정보가 반영된 마지막 시점을 뜻합니다.

쉽게 말하면 “이 날짜 이후의 사건은 모델이 기본적으로는 모른다”는 경계선입니다.

### 예시로 이해하기

만약 어떤 모델의 knowledge cutoff가 2025년 6월이라면:

- 2025년 5월 이전의 정보 → 학습되어 있을 가능성이 높음
- 2025년 7월 이후의 정보 → 기본 지식에는 없음

따라서 이런 질문은 어려워집니다.

“2026년 현재 삼성전자 주가는 얼마야?”

이건 cutoff 이후 정보이므로, 웹 검색 같은 외부 도구가 필요합니다.

### 왜 생기나?

LLM은 인터넷에 실시간 연결된 상태로 학습되는 것이 아닙니다.

특정 시점까지의 데이터를 모아 대규모 학습을 한 뒤 모델을 배포합니다.

그래서 학습이 끝난 시점 이후의 정보는 자동으로 업데이트되지 않습니다

- **Transformer 원논문**은 **Positional Encoding**(sin, cos)을 사용했습니다. 수학 공식으로 생성하므로 고정**되어 있고 학습되지 않습니다.
- **BERT**는 **Positional Embedding**을 사용했습니다. 위치마다 임베딩 벡터를 두고 **역전파를 통해 학습**합니다.
- BERT가 Positional Embedding을 선택한 이유는 **위치 정보도 데이터에 맞게 학습하면 더 유연하게 문장 구조를 표현할 수 있고, 실제 NLP 작업에서 더 좋은 성능을 보였기 때문**입니다.

> **Transformer는 현재 Context Window 안에 있는 정보만 사용할 수 있습니다.**
> 

따라서,

- **한정된 Context Window** → 한 번에 읽을 수 있는 길이가 제한됨.
- **Long-term Context 없음** → 너무 오래전 정보는 Context Window 밖으로 밀려나면 사용할 수 없음.
- **세션 간 기억 없음** → 대화가 종료되면 이전 대화 내용을 기본적으로 기억하지 못함.

즉, 이 문장의 의미는 **Transformer는 무한한 기억을 가진 모델이 아니라, 현재 입력(Context Window) 안의 정보만 활용하는 구조**라는 뜻입니다.

- **의미 이해의 부재**: **LLM은 사람처럼 의미(Semantics)를 이해하는 것이 아니라, 언어의 통계적 패턴을 학습하여 답변을 생성한다.**

- **추론 구조의 불명확성**: **LLM의 추론은 명시적인 논리 규칙을 적용하는 것이 아니라, 학습한 통계적 연관*과 확률에 기반하여 답을 생성하므로 내부 추론 과정을 명확하게 설명하기 어렵다.**

**Pruning은 중요하지 않은 가중치, 뉴런, 또는 레이어를 제거하여 모델의 크기를 줄이고 추론 속도를 높이는 모델 경량화 기법**입니다

| 기법 | 방법 | 목적 |
| --- | --- | --- |
| **Pruning** | 중요하지 않은 가중치·뉴런 제거 | 모델 크기 감소 |
| **Quantization** | 가중치의 비트 수를 줄임 (예: 32비트 → 8비트) | 메모리 절약, 속도 향상 |
| **Knowledge Distillation** | 큰 모델의 지식을 작은 모델에 학습시킴 | 작은 모델도 높은 성능 유지 |
